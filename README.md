# Pomodoro

A minimal, database-free timer with 30-minute, 1-hour, and 3-hour focus sessions plus 5- and 15-minute breaks. The interface uses lightweight typography and an original sumi-e-inspired SVG landscape.

## Run locally

```bash
python3 -m http.server 4173
```

Open <http://localhost:4173>.

## GitHub Pages

Create `bogireddytejareddy/pomodoro`, push this folder to its `main` branch, then choose **Settings → Pages → Deploy from a branch → main / root**.

The site will be available at <https://bogireddytejareddy.github.io/pomodoro/>.
